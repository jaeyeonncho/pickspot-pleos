# 픽스팟 UI 단계별 화면

현재 v0.27.0 연결 흐름의 UI 이미지 44장입니다. `index.html`을 열면 단계별 설명, 테마 필터와 원본 보기가 가능합니다.

## 이미지 출처

차량 36장: 현재 Android PickupScreen/TripPreviewPanel에 재현용 상태를 넣어 1600×900으로 렌더했습니다. 밝은/어두운 테마 각 18장입니다. 웹 8장: 현재 HTML·CSS를 사용한 고정 상태 자료 페이지를 가로 390px 브라우저로 촬영했습니다. 실제 만남·GPS·SDK 응답 성공 증빙으로 사용하지 않습니다.

참여 코드, 계산·만료 시각, Pleos 결과 수치는 이미지용입니다. 위치 관계도는 실제 도로 지도가 아닙니다. 실제 GPS 공유 웹은 별도 기능이며 이 묶음은 현재 연결 시연의 핵심 UI를 정리합니다.
