픽스팟 UI · 단계별 화면

v0.27.0 · 차량 36장 + 웹 8장 · 2026-11-15

현재 앱 레이아웃과 웹 마크업으로 상태를 재현한 화면 자료입니다. 실제 만남·위치·SDK 호출 결과를 촬영한 증빙이 아닙니다. 실제 서비스 화면을 새로 디자인한 목업도 아닙니다.

차량 1600×900, 밝은/어두운 테마. 웹은 가로 390px 전체 페이지입니다. 이미지를 클릭하면 원본을 볼 수 있습니다.
